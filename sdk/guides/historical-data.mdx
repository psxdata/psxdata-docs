# Download PSX historical stock prices with Python

psxdata returns complete OHLCV history for any PSX-listed stock in a single call.

## Data granularity

All historical data is **daily OHLCV bars**. One row per trading day.

Intraday historical bars (1-minute, 5-minute, 15-minute, and so on) are not available. PSX does not publicly expose historical intraday data through any official channel. For point-in-time quotes during trading hours, use [`psxdata.quote()`](/sdk/guides/realtime-snapshot) instead.

## Basic usage

```python
import psxdata

df = psxdata.stocks("ENGRO", start="2025-01-01", end="2025-12-31")
print(df.head())
```

Output:

```text
        date    open    high     low   close    volume  is_anomaly
0 2025-01-02  286.90  293.50  285.00  291.00   1234567       False
1 2025-01-03  291.00  295.00  289.00  293.50    987654       False
...
```

## Date filtering

`start` and `end` accept `str` (ISO format), `datetime.date`, or `None`.

```python
# Last 90 days
from datetime import date, timedelta

end = date.today()
start = end - timedelta(days=90)
df = psxdata.stocks("LUCK", start=start, end=end)
```

## Compute returns

```python
import psxdata

df = psxdata.stocks("HBL", start="2024-01-01")
df = df.sort_values("date").reset_index(drop=True)

df["daily_return"] = df["close"].pct_change()
df["cumulative_return"] = (1 + df["daily_return"]).cumprod() - 1

print(df[["date", "close", "daily_return", "cumulative_return"]].tail())
```

## Save to CSV or Excel

```python
import psxdata

df = psxdata.stocks("ENGRO", start="2021-01-01")
df.to_csv("engro_history.csv", index=False)
df.to_excel("engro_history.xlsx", index=False)
```

## Fetch multiple stocks

`psxdata.tickers()` returns a plain `list[str]` of symbols, and `psxdata.stocks()` returns OHLCV without a `symbol` column. When you loop over tickers, add the symbol to each frame yourself before combining them.

### Long-format DataFrame (one row per symbol per day)

Useful when you want to filter, group, or export every symbol's history together.

```python
import psxdata
import pandas as pd

symbols = psxdata.tickers(index="KSE100")  # list[str]

frames = []
for sym in symbols:
    try:
        df = psxdata.stocks(sym, start="2021-01-01")
    except Exception as exc:
        print(f"Skipped {sym}: {exc}")
        continue
    df["symbol"] = sym
    frames.append(df[["symbol", "date", "close", "volume"]])

long_df = pd.concat(frames, ignore_index=True)
print(long_df.head())
```

Wrap the call in `try` / `except` so one delisted or newly listed symbol does not stop the whole loop.

### Wide close-price matrix (one column per symbol)

Useful for correlation, portfolio, or index-construction work.

```python
import psxdata
import pandas as pd

tickers = ["ENGRO", "LUCK", "HBL"]
frames = {t: psxdata.stocks(t, start="2025-01-01") for t in tickers}

close = pd.DataFrame({t: df.set_index("date")["close"] for t, df in frames.items()})
print(close.tail())
```

<Tip>
  If you want ticker metadata alongside OHLCV (sector, market cap, and so on), call [`psxdata.symbols()`](/sdk/reference/client#psxdata-symbols) — that one returns a DataFrame with a `symbol` column you can merge onto the long-format frame above.
</Tip>

## Bypass cache

```python
# Always fetch fresh from PSX (slower)
df = psxdata.stocks("ENGRO", cache=False)
```
